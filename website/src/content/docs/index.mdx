  </Card>
  <Card title="Tree-sitter highlighting" icon="seti:default">
    Incremental parsing on a background thread, one language per npm package, fifteen packages at launch, injections for fenced blocks and embedded script.
  </Card>
  <Card title="Keyboard first" icon="laptop">
    Soft keyboards with composition, hardware keys, a toolbar API, and an editor that moves with the keyboard animation.
  </Card>
  <Card title="Android and iOS" icon="information">
