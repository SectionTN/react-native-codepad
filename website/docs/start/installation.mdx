## Requirements

- React Native 0.81+ with the New Architecture
- Android 7+ (API 24)
- iOS 17+

## Packages

Install the core, Nitro Modules and one package per language you want to highlight:

<Tabs groupId="package-manager">
<TabItem value="npm" label="npm">

```sh
npm install react-native-codepad react-native-nitro-modules react-native-codepad-lang-javascript
```

</TabItem>
<TabItem value="pnpm" label="pnpm">

```sh
pnpm add react-native-codepad react-native-nitro-modules react-native-codepad-lang-javascript
```

</TabItem>
<TabItem value="yarn" label="yarn">

```sh
yarn add react-native-codepad react-native-nitro-modules react-native-codepad-lang-javascript
```

</TabItem>
<TabItem value="bun" label="bun">

```sh
bun add react-native-codepad react-native-nitro-modules react-native-codepad-lang-javascript
```

</TabItem>
</Tabs>

Language packages are named `react-native-codepad-lang-<id>`. The [language list](/reference/languages/) has all fifteen.

## Rebuild

The packages carry native code, so rebuild the app after adding or removing one.

<Tabs groupId="framework">
<TabItem value="expo" label="Expo">

Expo development builds only, not Expo Go. Set the iOS deployment target to 17.0, then prebuild and run:

```json title="app.json"
{
  "expo": {
    "plugins": [
      // diff-add-start
      ["expo-build-properties", { "ios": { "deploymentTarget": "17.0" } }]
      // diff-add-end
    ]
  }
}
```

```sh
npx expo prebuild
npx expo run:ios
npx expo run:android
```

</TabItem>
<TabItem value="react-native" label="React Native">

Autolinking does the rest. Set the iOS deployment target in the Podfile, install the pods and run:

```ruby title="ios/Podfile"
# diff-remove
platform :ios, min_ios_version_supported
# diff-add
platform :ios, '17.0'
```

```sh
cd ios && pod install && cd ..
npm run ios
npm run android
```

</TabItem>
</Tabs>
