## Requirements

| | Minimum |
| --- | --- |
| React Native | 0.81, New Architecture only |
| React | 19 |
| react-native-nitro-modules | 0.37 |
| Android | API 24, `compileSdk` 36 |
| iOS | 17.0, Xcode 16 |

:::caution[Not on npm yet]
The packages publish with `0.1.0`. Until then, clone the [repository](https://github.com/SectionTN/react-native-codepad) and run the example app.
:::

## Rebuild

The packages carry native code. Rebuild after adding or removing one.

<Tabs groupId="framework">
<TabItem value="expo" label="Expo">

Expo development builds only, not Expo Go. Set the iOS deployment target to 17.0, then prebuild:

```json title="app.json"
{
  "expo": {
    "plugins": [
      // diff-add-start
      ["expo-build-properties", { "ios": { "deploymentTarget": "17.0" } }]
      // diff-add-end
    ]
  }
}
```

```sh
npx expo prebuild
npx expo run:ios
npx expo run:android
```

</TabItem>
<TabItem value="react-native" label="React Native">

Autolinking does the rest. Set the deployment target, install the pods and run:

```ruby title="ios/Podfile"
# diff-remove
platform :ios, min_ios_version_supported
# diff-add
platform :ios, '17.0'
```

```sh
cd ios && pod install && cd ..
npm run ios
npm run android
```

</TabItem>
</Tabs>
