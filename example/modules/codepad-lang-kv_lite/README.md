# codepad-lang-kv_lite

Generated by `npx react-native-codepad language`. Do not edit it by hand: change the grammar or its queries and run the command again.

Pass `language="kv_lite"` to `CodeEditor`. Theme token keys this package produces:

- `boolean`
- `comment`
- `number`
- `operator`
- `property`
- `string`

See the [custom languages guide](https://reactnativecodepad.pages.dev/guides/custom-languages/).
